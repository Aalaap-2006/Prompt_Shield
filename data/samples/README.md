# Benchmark samples (for tests / smoke runs)
Trimmed subsets of public benchmarks, kept for offline reproducibility. Full data: run `bash data/fetch_data.sh`.
- InjecAgent (Zhan et al., 2024) https://github.com/uiuc-kang-lab/InjecAgent  - 20 dh + 20 ds base cases, tools filtered to those used.
- BIPIA (Yi et al., 2023, Microsoft) https://github.com/microsoft/BIPIA - attack strings, 50 email + 20 table contexts.
Both are MIT-licensed upstream; keep their attribution in the paper.
